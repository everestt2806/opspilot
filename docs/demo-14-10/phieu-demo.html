Ý tưởng trong một câu

OpsPilot nhận diện mã nguồn, triển khai qua SSH và Docker, lưu phiên bản, kiểm tra khả năng truy cập, theo dõi vận hành và hỗ trợ khôi phục.

Luồng chính: Git repo/branch → commit SHA → Detect → Build → Deploy → Health/Exposure → Monitor/Doctor → Rollback.

Demo 6–8 phút

  1. Ứng dụng và máy chủ: xem trạng thái cùng thời điểm kiểm tra.
  2. Nhập repo Git công khai everestt2806/opspilot, nhánh main, thư mục demo-apps/express-api; xác nhận SHA và xem detector/BuildPlan của snapshot.
  3. Trình bày wizard deploy, lịch sử phiên bản và bằng chứng deploy theo chế độ đã chọn.
  4. Chỉ ra runtime/exposure, Doctor hoặc rollback khi có bằng chứng phù hợp.
  5. Giải thích pipeline ML; dữ liệu tổng hợp phải được gọi rõ là synthetic.
